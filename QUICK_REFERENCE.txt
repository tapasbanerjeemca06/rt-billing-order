SAMPLE QUERIES FOR TESTING
---------------------------

Test Sales Query:
SELECT ISNULL(SUM(GrandTotal),0) FROM tblBill 
WHERE BillDate BETWEEN '2024-01-01' AND '2024-01-31'

Test Expenses Query:
SELECT ISNULL(SUM(Amount),0) FROM tblExpense 
WHERE ExpDate BETWEEN '2024-01-01' AND '2024-01-31'

Test Stock Value Query:
SELECT ISNULL(SUM(i.SalePrice * ISNULL(si.Qty,0)),0) 
FROM tblItem i 
LEFT JOIN (SELECT ItemID, SUM(Qty) AS Qty FROM tblStockIn GROUP BY ItemID) si 
ON i.ItemID=si.ItemID

Test Top Items Query:
SELECT TOP 10 i.ItemName, SUM(bd.Amount) AS Total 
FROM tblBillDetail bd 
INNER JOIN tblItem i ON bd.ItemID=i.ItemID 
INNER JOIN tblBill b ON bd.BillID=b.BillID 
GROUP BY i.ItemName 
ORDER BY Total DESC

TROUBLESHOOTING
---------------
If dashboard shows no data:
- Verify database connection in DBModule.vb
- Check if demo data was inserted (run DemoData.sql again)
- Verify connection string matches your SQL Server instance
- Check if SQL Server service is running

If queries fail:
- Ensure SQL Server 2008 or higher is installed
- Verify SQLOLEDB provider is available
- Check user 'sa' has proper permissions
- Test connection using TestConnection() function
